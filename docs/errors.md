# JIJU 错误码与用户可见错误

## 1. 依据与响应约定

本文依据 `docs/product/PRD-v1.1.md` 第 5.1 节“权限矩阵”、第 5.9 节“用户可见错误”和第 8 节“功能需求”整理，并与 [permissions.md](permissions.md) 的角色和服务端校验点配合使用。

服务端错误响应至少包含：

- `code`：稳定业务错误码。
- `message`：经过审核的用户可见文案。
- `request_id`：服务端请求追踪标识。
- `details`：可选，只允许包含字段名、字段级安全提示和配额解除时间等白名单信息。

禁止在错误响应中返回堆栈、SQL、内部主机名、内容是否存在、到期/隐藏/删除状态差异、审核规则、浏览量、浏览者身份或其他敏感实现细节。

## 2. 错误码表

| code | HTTP 状态 | 分类 | 用户可见文案 | 触发场景 | 是否可重试 |
| --- | --- | --- | --- | --- | --- |
| JIJU_AUTH_4011 | 401 | 未登录 | 请先登录后继续 | 游客调用发布、评论、轻互动、举报、查看“我的”、查看浏览量等需要登录的接口 | 可；保留原页面、操作意图和本地草稿，登录成功后重试原操作 |
| JIJU_AUTH_4012 | 401 | 登录失效 | 登录状态已失效，请重新登录 | 令牌过期、被撤销、服务端会话不存在或登录态无法验证 | 可；重新登录后恢复原页面和操作，可重试原请求 |
| JIJU_AUTH_4013 | 401 | 后台登录失败 | 账号或密码错误 | 后台账号不存在、密码错误或账号凭据已停用；不得提示具体哪一项错误 | 否；确认账号和密码后重新登录 |
| JIJU_ACCESS_4031 | 403 | 权限不足 | 你无权执行此操作 | 已登录非作者尝试编辑/删除他人内容、非审核人员访问后台、用户直接请求无权查看的浏览量 | 否；用同一身份自动重试仍会失败，需使用具备权限的身份或返回 |
| JIJU_ACCESS_4032 | 403 | 使用须知未确认 | 请先阅读并确认当前版本使用须知 | 用户首次表达或互动前尚未确认当前协议版本 | 可；完成当前版本须知确认后重试原操作 |
| JIJU_CONTENT_4041 | 404 | 内容不可用 | 内容已不可用 | 非作者访问到期、隐藏或删除的帖子/评论；目标不存在；无权查看普通详情但不得泄露存在性 | 否；返回或刷新广场，不对同一目标连续自动重试 |
| JIJU_CONTENT_4221 | 422 | 内容状态不允许操作 | 内容已不可用 | 已到期、已删除或 REJECTED 内容不允许执行恢复等状态动作；其他内容生命周期不允许的操作 | 否；刷新当前状态后由用户决定是否返回 |
| JIJU_VALIDATION_4221 | 422 | 内容校验失败 | 内容不符合要求，请修改后重试 | 帖子正文、评论、标签、举报原因或“其他”说明未通过服务端校验；非法字段或非法状态值 | 可；修正输入后重试，使用新的用户意图幂等键 |
| JIJU_QUOTA_4291 | 429 | 配额满 | 今日发帖次数已达上限，请于 {next_available_time} 后重试 | 当前账号在国内自然日内已成功发布 5 篇帖子 | 可；到达返回的时间后重试 |
| JIJU_QUOTA_4292 | 429 | 配额满 | 评论过于频繁，请于 {next_available_time} 后重试 | 当前账号在连续 60 分钟内已成功发布 10 条评论 | 可；到达返回的时间后重试 |
| NETWORK_ERROR | 无（客户端未收到 HTTP 响应） | 网络失败 | 网络连接失败，请检查网络后重试 | 请求超时、断网、DNS/连接失败、请求被中断或客户端未收到响应 | 可；恢复网络后使用同一幂等键重试原操作，并保留用户输入 |
| JIJU_SYSTEM_5031 | 503 | 服务暂时不可用 | 服务暂时不可用，请稍后重试 | 服务端依赖暂时不可用、发布或查询链路熔断、服务端明确返回 5xx 且无法归类 | 可；按有限次数退避重试，保留用户输入和幂等键 |
| JIJU_CONFLICT_4091 | 409 | 状态冲突 | 内容状态已变化，请刷新后重试 | 当前状态与动作不匹配、同一幂等键对应不同载荷、非法状态迁移 | 可；刷新当前状态并按新的用户意图生成新幂等键后再操作 |
| JIJU_CONFLICT_4092 | 409 | 版本冲突 | 内容已更新，请刷新后重试 | 编辑或审核提交基于旧内容版本，或当前状态版本已被并发修改 | 可；重新读取最新版本和状态后，由用户确认是否重试 |
| JIJU_MODERATION_4091 | 409 | 审核状态写入被拒绝 | 当前操作不被允许 | 客户端尝试修改审核状态，或非授权流程尝试改变复核结论 | 否；不得由客户端重试该状态写入 |
| JIJU_MODERATION_4092 | 409 | 需要确认风险提示 | 请确认风险提示后再发布 | 内容命中需复核规则但尚未完成当前提示版本的确认；响应返回 challenge_id、提示版本和求助资源 | 可；展示提示并取得用户确认后，使用 challenge_id 和 risk_acknowledged=true 重试 |

## 3. 必须区分的错误类别

| 类别 | 区分规则 | 对应用户处理 |
| --- | --- | --- |
| 未登录 | 请求没有有效登录态，返回 `JIJU_AUTH_4011`；不得先查询业务对象。 | 进入登录流程，成功后恢复原页面和原操作。 |
| 登录失效 | 曾经登录但当前会话无效，返回 `JIJU_AUTH_4012`；与“未登录”独立。 | 重新登录，保留草稿和操作意图。 |
| 权限不足 | 登录有效但当前身份无权执行，返回 `JIJU_ACCESS_4031`。 | 返回，或改用具备权限的身份；不得自动重试。 |
| 内容不可用 | 非作者无法访问到期、隐藏、删除或不存在对象，统一返回 `JIJU_CONTENT_4041` 和“内容已不可用”。 | 返回或刷新列表，不展示具体不可用原因。 |
| 内容校验失败 | 服务端判定输入不合法，返回 `JIJU_VALIDATION_4221`。 | 定位字段并保留输入，修改后重试。 |
| 配额满 | 发帖日配额或评论滚动窗口配额用完，分别返回 `JIJU_QUOTA_4291` 或 `JIJU_QUOTA_4292`。 | 展示解除时间，到期后再试。 |
| 网络失败 | 客户端没有收到服务端响应，使用客户端本地 `NETWORK_ERROR`；不得由服务端伪造该码。 | 提示检查网络，保留输入，用同一幂等键重试。 |

## 4. 响应安全规则

### 4.1 内容不可用与权限不足

- 对非作者访问到期、隐藏、删除或不存在内容，必须返回相同的 `JIJU_CONTENT_4041`、HTTP 404、文案和响应结构，不得返回“已到期”“已下架”“已删除”或“存在但无权”。
- 对已登录用户越权查看浏览量，返回 `JIJU_ACCESS_4031`；服务端必须先完成身份和作者资格判断，再决定是否查询目标，存在与不存在对象使用同一响应。
- 对游客请求浏览量，先返回 `JIJU_AUTH_4011`，不得先校验对象是否存在。
- 权限错误和内容不可用不得互相伪装；但两者的具体数据都不得用于推断对象存在性。

### 4.2 重试与幂等

- 网络失败和可恢复服务故障必须保留用户输入，并复用原 `Idempotency-Key`。
- 未登录、登录失效、须知未确认后恢复并重试原操作时，复用原意图的幂等键。
- 内容校验失败后用户修改了载荷，应生成新的幂等键，避免旧请求结果覆盖新输入。
- 配额满、权限不足和内容不可用不得自动循环重试。
- 状态冲突或版本冲突后，必须先刷新服务端状态；重试构成新的用户意图时使用新幂等键。
- 配额满文案中的时间标签必须替换为可直接展示的国内日期和时间，例如“2026-11-14 00:00”。

### 4.3 文案安全

- `message` 只能使用本文定义的用户可见文案；动态配额时间使用北京时间展示。
- `details` 可返回字段名和安全提示，不得回显正文、评论、举报说明、命中规则、对象作者或内部状态。
- 错误日志与埋点不得记录正文、评论、举报说明或其他敏感内容；排查使用 `request_id`。

## 5. 最小验收测试

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| ERR-01 | 游客调用发布和评论接口 | 返回 `JIJU_AUTH_4011`，保留本地草稿与操作意图。 |
| ERR-02 | 会话过期后调用已登录接口 | 返回 `JIJU_AUTH_4012`，与从未登录可区分。 |
| ERR-03 | 登录非作者直接请求浏览量 | 返回 `JIJU_ACCESS_4031`；存在和不存在的合法 ID 响应一致。 |
| ERR-04 | 非作者分别访问到期、隐藏、删除和不存在的帖子详情 | 均返回 `JIJU_CONTENT_4041` 和“内容已不可用”，响应结构一致。 |
| ERR-05 | 提交空帖子或超过长度上限的评论 | 返回 `JIJU_VALIDATION_4221`，保留输入并定位字段。 |
| ERR-06 | 当日第 6 次发帖 | 返回 `JIJU_QUOTA_4291`，展示北京时间下一次可发布时间。 |
| ERR-07 | 连续 60 分钟内第 11 条评论 | 返回 `JIJU_QUOTA_4292`，展示北京时间解除时间。 |
| ERR-08 | 客户端请求超时或无网络 | 显示 `NETWORK_ERROR`，保留输入，使用同一幂等键重试。 |
| ERR-09 | 客户端尝试修改审核状态 | 返回 `JIJU_MODERATION_4091`，不产生状态变更。 |
| ERR-10 | 扫描错误响应和日志 | 不含正文、评论、举报说明、浏览量、浏览者身份、隐藏原因或内部堆栈。 |

# JIJU 视觉配色规范

## 设计方向

JIJU 的情绪表达界面以“温暖、安静、不过度刺激”为原则。基础背景使用奶油色和浅杏色，主操作使用陶土红，提示使用蜂蜜金，成功状态使用柔和橄榄绿。避免大面积冷灰、蓝绿和荧光色。

## 使用规则

1. 主按钮、选中态和关键交互使用陶土红；同一屏不得同时出现多个竞争性主色块。
2. 风险确认、配额和须知提醒使用蜂蜜金；错误和失败使用暖红。
3. 橄榄绿只用于成功、完成和通过状态，不用于主操作。
4. 状态不能只依赖颜色表达，必须同时提供文字或勾选标记。
5. 新组件优先复用以上颜色令牌，不新增冷色系主色。
6. 正文与背景、按钮文字与按钮背景必须满足可读性对比；重点文字建议使用主文字色。

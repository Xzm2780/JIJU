# JIJU 视觉设计规范

## 设计方向

界面采用偏冷的暖色体系：以暖象牙和柔和玫瑰为主调，保持安静、亲近和克制。主色、状态色和背景必须形成清晰层级，不使用高饱和色或冷暖主色混搭。

## 组件规则

1. 同一屏只使用一个主操作视觉焦点；次操作使用浅色表面或描边。
2. 公开属性确认使用原生勾选框，不使用开关替代。
3. 三个及以上并排选项使用 `flex: 1 1 0`、`width: 0` 和 `min-width: 0`，窄屏下不得交叠。
4. 列表卡片和设置项内容贴齐主内容区，不额外收窄或居中。
5. 长文本按容器安全换行；列表摘要按明确行数显示省略号，不硬裁切字形。
6. 输入框文字、占位文字、标签和操作按钮必须保持可读对比度。
7. 状态不能只依赖颜色，应同时提供文字、图标或勾选状态。
8. 小程序与运营后台复用同一颜色令牌和语义层级，不分别维护近似色。

# JIJU 微信小程序

原生微信小程序 + TypeScript，实现 T05 发布页、模拟登录恢复、须知确认、标签目录读取、发布和成功预览。

## 启动

先启动 `server/` API，默认地址为：

```text
http://127.0.0.1:3001/api/v1
```

用微信开发者工具导入当前 `frontend/` 目录。项目使用 `touristappid` 并关闭开发阶段的合法域名检查，仅用于本地演示。

API 地址配置在 `miniprogram/app.ts` 的 `globalData.apiBaseUrl`。

## 校验

```powershell
npm install
npm run typecheck
npm test
```

## 页面流程

1. 游客编辑正文、标签、留存时长和公开属性确认。
2. 草稿保存在本机最多 24 小时。
3. 点击发布后才触发模拟登录；取消登录保留草稿。
4. 登录后恢复原内容，并在需要时展示使用须知。
5. 服务端返回 `409 JIJU_MODERATION_4092` 时展示提示和资源版本。
6. 确认风险后带 challenge 与新幂等键重试。
7. 发布成功后跳转详情预览，展示审核状态和北京时间到期时间。

发布页使用紧凑的公开提示卡和原生勾选框确认公开属性；留存时长使用三等分可收缩按钮，窄屏下仍应完整显示 24 小时、3 天和 7 天三个选项。

界面基础配色使用奶油背景、陶土红主操作和蜂蜜金提示，具体颜色令牌见 [视觉配色规范](../docs/ui-design.md)。

## 非目标

- 不实现真实微信服务端换取、账号永久注销、评论、互动、举报或后台。
- 不把客户端校验作为最终授权或内容安全判断。
- 不在小程序内硬编码标签配置；标签必须来自 `GET /tags`。

# JIJU 微信小程序

原生微信小程序 + TypeScript，已实现广场、帖子详情、发布、编辑删除、评论、轻互动、我的帖子、举报、登录会话、须知确认和账号注销。

## 启动

先启动 `server/` API，默认地址为：

```text
http://127.0.0.1:3001/api/v1
```

用微信开发者工具导入当前 `frontend/` 目录。项目使用 `touristappid` 并关闭开发阶段的合法域名检查，仅用于本地演示。

API 地址配置在 `miniprogram/app.ts` 的 `globalData.apiBaseUrl`。

## 校验

```powershell
npm install
npm run typecheck
npm test
```

## 页面

- `pages/feed`：广场稳定游标分页、刷新、错误和到底状态。
- `pages/detail`：详情、评论、举报、轻互动和作者操作。
- `pages/publish`：草稿、登录恢复、须知、标签、留存和风险确认。
- `pages/edit`：作者编辑和版本冲突处理。
- `pages/my`：本人有效/到期/下架帖子、筛选、退出和永久注销。
- `pages/notice`、`pages/report`：使用须知与举报流程。

发布页使用紧凑的公开提示卡和原生勾选框确认公开属性；留存时长使用三等分可收缩按钮，窄屏下仍应完整显示 24 小时、3 天和 7 天三个选项。

## 视觉设计

整体采用偏冷调的暖色体系：

- 背景：暖象牙 `#F5F0EE`
- 卡片：柔和暖白 `#FFFCFB`
- 主色：低饱和烟熏玫瑰 `#A5686C`
- 主色深调：`#7C4C52`
- 主色浅底：`#F1E0E2`
- 正文：暖炭色 `#30292A`
- 提示色：柔和陶土 `#926435`

危险、警告和成功状态仍保留独立语义色，不使用颜色作为唯一状态提示。

完整颜色令牌和组件规则见 [视觉设计规范](../docs/design/ui-guidelines.md)。

## 非目标

- 运营后台由 API 服务提供，不在小程序内展示。
- 不把客户端校验作为最终授权或内容安全判断。
- 不在小程序内硬编码标签配置；标签必须来自 `GET /tags`。
- 不把 `can_delete`、`is_author`、`my_reaction` 等服务端提示当成授权依据。

# T00 任务包：应用地基与公共壳

## 1. 任务名（Task name）

应用地基与公共壳

## 2. 范围（Scope）

- 页面：应用启动壳、底部导航壳和公共加载/错误/空态容器。
- 建立前后端工程边界、配置加载、依赖注入入口和测试骨架。
- 建立统一错误映射、请求追踪、幂等键与浏览量去重标识的公共客户端能力。
- 建立 UTC 存储、北京时间展示和 Unicode 扩展字素簇工具的公共契约。

## 3. 非目标（Non-goals）

- 不实现广场、详情、发布、评论、互动、我的或任何后台业务页面。
- 不新增产品接口。
- 不定义业务权限、内容审核规则或数据保留期限。
- 不引入未批准框架、SDK、数据库或监控依赖。

## 4. 前置任务（Dependencies）

无。

## 5. 相关 PRD 需求 ID

AUTH-01、FEED-07、NFR-PERF-04、NFR-REL-02、NFR-SEC-01、NFR-SEC-03、NFR-SEC-04

## 6. 相关 AC

无直接 AC；为 AC-01～AC-24 提供公共工程和错误处理能力。

## 7. 涉及接口（Interfaces）

无新增产品接口。

## 8. 涉及表（Tables）

不新增业务表；按 `docs/data-model.md` 建立迁移、事务和测试数据基础设施。

## 9. 实现要点（Implementation points / core rules）

1. 应用壳只负责启动、导航容器和公共状态，不包含业务判断。
2. 所有请求经统一适配层处理认证头、`request_id`、错误码映射、网络失败和用户输入保留。
3. 提供 UTC 时间解析、北京时间展示、扩展字素簇计数和空值处理基础工具。
4. 提供 `Idempotency-Key` 与 `X-View-Token` 的生成、复用和格式校验能力，二者不得混用。
5. 日志和埋点从第一天采用白名单，禁止采集正文、评论、举报说明和敏感身份字段。

## 10. 测试要求（Test requirements）

- `[AUTO]` 单测：错误码到用户提示映射、UTC/北京时间转换、字素簇工具、幂等键和视图令牌格式。
- `[AUTO]` 接口：统一错误响应包含安全 `message` 和 `request_id`，不返回堆栈。
- `[AUTO]` 安全：日志快照不包含敏感输入类型。
- `[MANUAL]` UI：应用壳在加载、空态、网络失败和受限宽度下的展示可读。

## 11. 完成定义（Definition of done）

- 应用可启动并进入空导航壳，公共错误与加载组件可独立验证。
- 公共请求、时间、字素计数、幂等和日志脱敏测试全部通过。
- 后续任务可以在不新建工程或重复基础设施的前提下接入页面和接口。
- 未引入未批准依赖，未新增产品接口或业务规则。

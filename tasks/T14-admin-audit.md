# T14 任务包：后台审计查询

## 1. 任务名（Task name）

后台审计查询

## 2. 范围（Scope）

- 页面：后台审计查询页。
- 接口：`GET /admin/audit-logs`。
- 支持按操作者、动作、对象、内容版本和时间范围筛选。

## 3. 非目标（Non-goals）

- 不允许编辑或删除审计记录。
- 不展示正文、评论正文、举报说明、浏览者身份或敏感令牌。
- 不提供普通用户端审计入口。
- 不定义审计保留期限。

## 4. 前置任务（Dependencies）

T11、T12、T13

## 5. 相关 PRD 需求 ID

MOD-06、MOD-08、MOD-09、NFR-SEC-05

## 6. 相关 AC

AC-06、AC-19；同时支撑 MOD-06、MOD-09 的治理追溯要求。

## 7. 涉及接口（Interfaces）

`GET /admin/audit-logs`

## 8. 涉及表（Tables）

AuditLog、AdminRoleAssignment

## 9. 实现要点（Implementation points / core rules）

1. 只允许 AUDITOR 或具有审计范围的 CONTENT_MODERATOR 后台身份访问。
2. 查询使用服务端游标分页，时间筛选采用 RFC 3339 UTC，服务端再按角色展示。
3. 返回操作者、角色快照、动作、对象、内容版本、原因和发生时间。
4. 不返回内容正文、举报说明、浏览量、浏览者身份或敏感令牌。
5. 审计记录只追加，不改写；敏感查询可按批准安全策略记录访问审计。

## 10. 测试要求（Test requirements）

- `[AUTO]` 接口：角色鉴权、筛选、时间边界、游标分页和空结果。
- `[AUTO]` 越权：普通用户、作者和低权限后台角色无法读取审计。
- `[AUTO]` 数据裁剪：响应不含正文、举报说明、浏览量和敏感身份。
- `[AUTO]` 并发：新增审计记录时原游标不重复返回同一记录。
- `[MANUAL]` UI：筛选、时间展示、对象跳转和敏感字段检查。

## 11. 完成定义（Definition of done）

- 授权审计人员可按对象、动作、操作者和时间查询治理记录。
- 审计记录不可由普通业务修改，敏感数据不出现在响应中。
- 相关后台动作的审计链可通过本任务追溯。
- 本任务仅使用 `GET /admin/audit-logs`，未定义审计保留期限。
